# EssentialSnap API

Deploy this folder to a Python web host such as Render. Free instances may sleep and have limited processing/time/storage.

The API only handles supported publicly available media links and does not accept credentials or cookies. Do not use it to bypass private-account access, DRM, or platform protections. Platform changes may break compatibility.

Endpoints: POST /api/info and POST /api/download. See the parent README for frontend configuration.
