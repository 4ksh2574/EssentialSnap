# EssentialSnap

Minimal, mobile-friendly GitHub Pages utility for opening social links, previewing supported YouTube links, and saving files selected from your device or direct URLs where permitted.

## Deploy
This repository uses GitHub Actions to publish the root directory to GitHub Pages. Enable **Settings → Pages → Source: GitHub Actions**.

## Limitations
This static app does not extract platform streams or bypass DRM, account restrictions, or platform protections. Use official download/export features or direct media links you are authorized to save.
